## ✦ Overview

This portfolio is a lightweight, responsive personal website designed around a **minimal editorial aesthetic with a calm, nature-inspired visual language**.

Rather than relying on a traditional developer portfolio layout, the interface combines:

* Clean typography
* Editorial-style layouts
* Forest and earth-inspired tones
* Soft glass-like surfaces
* Subtle decorative elements
* Responsive interactions
* Accessible semantic markup

The goal is to create a portfolio that feels **personal, intentional, and professional** while keeping the implementation lightweight and easy to maintain.

# ✨ Features

## 🎨 Premium Visual Design

* Editorial-inspired layout
* Nature-inspired visual identity
* Soft glass-style cards and surfaces
* Carefully balanced whitespace
* Custom decorative SVG elements
* Responsive typography
* Smooth visual hierarchy

## 📱 Fully Responsive

Designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

The layout adapts naturally to different screen sizes without compromising the visual hierarchy.

## ⚡ Lightweight & Fast

The portfolio intentionally keeps the frontend simple:

* Minimal JavaScript
* No unnecessary frameworks
* Lightweight HTML structure
* Tailwind CSS utilities
* Inline SVG graphics
* Embedded assets where appropriate

## ♿ Accessibility

Accessibility is considered throughout the interface with:

* Semantic HTML elements
* ARIA labels where necessary
* Keyboard-friendly interactions
* `focus-visible` states
* Decorative elements marked appropriately
* Reduced-motion support

## 🧩 Modular Sections

The portfolio is organized into clear sections:

* Hero
* About
* Skills
* Projects
* Education
* Beyond Code
* Contact

This makes the website easy to expand as new projects and experiences are added.

# ⚙️ Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/janmesh-codes/Portfolio_GSJ.git
```

## 2. Navigate to the project

```bash
cd portfolio
```

## 3. Open the website

Simply open:

```text
index.html
```

in your browser.

For the best development experience, use **VS Code + Live Server**.

# 🌱 Design Philosophy

> **Simple interfaces. Thoughtful details. Useful experiences.**

The portfolio intentionally avoids excessive visual effects and focuses instead on:

**Clarity → Personality → Usability → Performance**

Every visual element should support the content rather than compete with it.
